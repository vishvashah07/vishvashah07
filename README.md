## 🔨 Featured Project

### 🎓 ExamPrep AI — RAG-Powered Study Assistant
> Upload any PDF and chat with it. Quiz yourself, get summaries, create flashcards.

**Built with:** Python · FastAPI · LangChain · Pinecone · Gemini 3 Flash · React

- End-to-end **Naive RAG pipeline** — PDF ingestion, chunking, vector embeddings, semantic search
- **4 study modes** — Chat, Quiz, Summarize, Flashcards — each with dedicated LLM prompts
- **Anti-hallucination** — context-only responses with source + page number labeling
- FastAPI REST backend + React frontend with drag-and-drop PDF upload
